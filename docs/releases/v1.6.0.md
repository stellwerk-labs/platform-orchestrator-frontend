# Console v1.6.0

## Administration

The sidebar now opens **Administration**, with tabs for **Plugins** and
**Configuration**. Installation administrators can set session limits and switch
deployment maintenance on or off. Saved settings use revisions, so a stale editor
must reload before overwriting another administrator's change.

Browser sessions expire after 15 minutes without user activity by default.
CLI user tokens default to a fixed 2-hour lifetime. Both values are configurable;
changes also apply to existing sessions. Background polling does not keep a
browser session alive. Service and Runner tokens are outside this policy.

Maintenance refuses new deployments and managed observations while admitted
work finishes. The status shows deployment, reservation, admission, observation
and plugin counts. Start maintenance work only when the status is **Ready**.
Unknown or incomplete evidence prevents readiness. Turning maintenance off
resumes admission and plugin scheduling.

## Provider retirement

Deleting a Provider now requests retirement. The Console displays its state
while retained resources are removed, rather than implying immediate deletion.
A retiring Provider cannot provision new resources; removal remains available.
The retirement request does not destroy retained resources. Remove them through
the normal resource lifecycle. After state cleanup and its completion evidence,
the orchestrator removes the Provider.

## Upgrade

Use IAM 2.7.0, Control Plane 4.0.0 and Data Plane 4.3.0 with matching gateway
routes. Upgrade all Control Plane and Data Plane writers, then the Console and
other clients, then enable `PROVIDER_RETIREMENT_ENABLED=true` before requesting
Provider retirement. Retirement is disabled by default; DELETE returns HTTP 503
`provider_retirement_not_enabled` until activated. Once enabled, Control Plane
4.0.0 accepts retirement with HTTP 202 instead of HTTP 204. Older clients may
report an error even though retirement was accepted.

Database migrations require a backup and tested restoration plan. Reverting only
an image over a newer database schema is not a supported recovery procedure.
