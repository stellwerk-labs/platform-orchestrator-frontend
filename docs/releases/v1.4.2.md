# Orchestrator Console v1.4.2

This release carries forward the Console v1.4.1 security and compatibility
updates. It also makes public image publication wait for the exact OCI graph to
become readable after the registry accepts the copy. The wait is bounded and
read only; a different digest, authentication failure or transport error stops
publication.

The v1.4.1 publication did not complete. Its GitHub release remains a draft
without assets, while its original OCI image graph became publicly readable.
This successor uses a new version and new artifacts; it does not overwrite or
resume the incomplete v1.4.1 publication.

## Security and compatibility

Axios, React Router, YAML parsing, Orval, Vite, Vitest and affected transitive
dependencies are updated. Orval 8 generation retains the Axios transport,
request/response contracts and existing API wire values. Builds use Node 22.23.3
and pnpm 10.17.0. The serving image uses NGINX 1.30.5 and OpenSSL 3.5.8.

The 48-hour minimum dependency release age is configured where pnpm reads it.
Supplemental licence evidence is refreshed against the upstream MIT notice.

The development-only jscpd duplication check still depends on braces 3.0.3,
which is affected by
[GHSA-vfj7-8cjw-p6xm](https://github.com/micromatch/braces/issues/84).
No upstream fix is available. The maintainer accepted only its existing use
with this repository's trusted, checked-in patterns on 22 October 2026. The
finding and nonzero audit result remain visible, and the duplication gate and
threshold remain enabled. This package is not shipped in the browser bundle.
The exception does not cover untrusted patterns or other dependencies.

## Upgrade

The coordinated application patch set is Control Plane 3.1.1, Data Plane 4.0.1,
IAM 2.5.1 and Console 1.4.2. Use verified public artifacts for the selected set.
This patch adds no server database migration. Refresh the browser after the
upgrade to load the new static assets. Retain a compatible application revision
for recovery.

This release does not update the Runner, plugin runtime or external services.
Their separate security holds remain in effect.
