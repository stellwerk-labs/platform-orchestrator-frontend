# Console v1.5.0-rc.1

Prerelease for testing Module authoring with the coordinated CP 3.2, DP 4.1
and gateway changes.

## Module Drafts

Create a Draft, edit it and save each reviewed revision. If another author changes
the stored revision, reload the Draft before continuing; stale edits are rejected.
Capture a saved revision explicitly for one Environment. Capture does not
deploy. Select the captured snapshot and choose **Run captured test** to execute
it with a deployment manifest. Later Draft edits leave earlier captures and
test deployments unchanged.

Publishing closes the Draft and freezes the exact reviewed revision as a
separate immutable `Proposed` Module Version. It does not make that Version
Default or deploy it. Existing Module Versions and Pins remain unchanged.

## Resource Type interfaces

Review interface history and publish an exact next consecutive interface
version. Declare the selected interface version in each new Module Version;
publishing a later interface does not change existing Module Versions or Pins.

## Compatibility

Use matching server APIs and gateway routes. An unavailable Draft test endpoint
reports an error; the Console never substitutes an ordinary deployment or
another Module Version. The curated API schema sources are recorded in
`apps/main/schemas/README.md`.

Final packaged upgrade and plugin compatibility checks remain part of the
coordinated release qualification.
