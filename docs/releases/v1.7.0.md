# Console 1.7.0

Administration displays the current maintenance state on a colored **Maintenance mode ON/OFF** button. Changing it retains the existing confirmation, revision checks, operator permissions and pending/error behavior.

The Modules table combines Resource Type, Has proposed, Default verified and No default filters with name, technical ID and Resource Type search. Reset clears the selection. Version-based filters use complete catalogue summaries from Control Plane 4.1.0, not paginated version history. If summaries are missing or version-read permission is absent, those filters are unavailable instead of interpreting unknown data as false.

Verification itself is unchanged. Current versions support only `unverified`, so Default verified intentionally returns no matches until verification becomes available. The Console explains this limitation.

No new dependency or API mutation is introduced by the filters. Existing maintenance API and session contracts remain required.

Protected Runner log views now display Runner and Terraform/OpenTofu messages
with compact metadata and highlighted JSON details. A Raw toggle retains the
original content. Unknown fields, malformed records and partial lines remain
visible. Large or highly expanded logs fall back to one plain view instead of
constructing thousands of highlighted rows. Protected content remains inside
the Console host; plugin frames do not receive it. Decryption, permissions and
key handling are unchanged.
